### What is this repository for? ####
* Quick summary: 
 Publicly available code, documents, and small data for data analysis for several published studies in the Orr Lab.
* We have tested the code in macOS and it should work fine in a Unix machine. 
 To use the code, we recommend this repository be cloned in `~/projects/`.
